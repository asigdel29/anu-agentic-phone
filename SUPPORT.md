# Support

**Questions and problems:** open an
[issue](https://github.com/asigdel29/anu-agentic-phone/issues). There are two templates — one
for something that behaves wrongly, one for a decision or a design question.

**Vulnerabilities:** not an issue. [`SECURITY.md`](SECURITY.md) has the private route, and a
public issue for a finding in an application that reads other applications' screens is a
disclosure.

**What to expect.** This is a personal project with one author and no support commitment. An
issue that states a problem clearly is likely to get an answer; an issue asking for a feature
may sit. Both are better filed than not — the issue list is where the reasoning for this
repository accumulates, and several of the things in it are open because somebody decided they
should be rather than because nobody looked.

**Before filing**, `docs/decisions/INDEX.md` routes most *why is it like this* questions to the
change that argued it.
